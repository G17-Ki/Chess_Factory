# 黄丹青完整课程开局招法手册（15门）

## 1. 使用说明

本手册只整理已达到整课 `complete` 的 15 门课程：C03–C07、C15、C16、C23、C24、C39–C44。

- 共 **228 条变化、1001 着**，全部通过 UCCI、中文记谱和 FEN 连续性校验。
- 着法按红、黑双方行棋顺序排列，`；` 用于分隔半回合。
- `HDQ-Cxx-yy` 为正式变化 ID，可在 `content/huangdanqing-moves/Cxx.json` 中查看完整父子关系、逐步 FEN、原话和校验状态。
- 老师棋理与原讲保持原貌；未运行 Pikafish，不添加引擎评分或“最佳着法”标签。
- C08–C14、C25–C27、C30–C34 仍有缺口，未混入本手册。

## 2. 中炮开局总纲

### 2.1 先记住三条原则

1. **快速出动大子**：车、马、炮先进入有效位置，不因贪吃兵卒拖慢出子。
2. **占据有利地形**：车去卒林或巡河线，马寻找河口和中路，炮配合牵制。
3. **活通子力**：通过挺兵、兑兵、移炮解决车马受堵。

中卒不仅是兵，也是将帅防线。屏风马用双正马守中卒；单提马、边马和中炮结构则必须额外评估中路安全。

### 2.2 中炮对屏风马的基本形

```text
炮二平五；马八进七；马二进三；车九平八；车一平二；马二进三
```

来源：C03-03、C04-00、C05-00。

黑方三、七卒未挺时，红方有两大选择：

- **进七兵过河车**：偏急攻，保留更多中路变化。
- **进三兵边马**：偏缓攻，形成五七、五八、五六炮等结构。

## 3. 中炮对屏风马

### 3.1 进七兵过河车

```text
炮二平五；马八进七；马二进三；车九平八；车一平二；马二进三；兵七进一；卒七进一；车二进六
```

来源：C05-01。

要点：先活通八路马，再以过河车阻止炮8进4封锁。红方暂不急着给左边马炮定型。

### 3.2 进三兵边马

```text
炮二平五；马八进七；马二进三；车九平八；车一平二；马二进三；兵三进一；卒三进一；马八进九
```

来源：C05-02。

后续转换：

- 炮八平七 → 五七炮（C05-03）
- 炮八进四 → 五八炮（C05-04）
- 炮八平六 → 五六炮（C05-05）

这些与进七兵过河车中的同名炮阵不是同一结构，不能混用棋谱。

### 3.3 黑方强挺7卒

```text
炮二平五；马八进七；马二进三；卒七进一；车一平二；车九平八；车二进六；马二进三；兵七进一
```

来源：C05-06。

黑方主动排除进三兵体系，红方仍按进七兵过河车展开。

### 3.4 黑方强挺3卒

```text
炮二平五；马八进七；马二进三；卒三进一；车一平二；车九平八；兵三进一；马二进三；马八进九
```

来源：C05-07。

黑方主动排除进七兵体系。若暂时不想主修进三兵，可用 C06-04 的巡河车简化搭配：

```text
炮二平五；马八进七；马二进三；卒三进一；车一平二；车九平八；车二进四；马二进三；兵七进一；卒三进一；车二平七
```

随后黑方可炮2退1或挺7卒活马，见 C06-05、C06-06。

### 3.5 过河车后的急进中兵

```text
炮二平五；马八进七；马二进三；车九平八；车一平二；卒七进一；车二进六；马二进三；兵七进一；炮八平九；车二平三；炮九退一；兵五进一；炮九平七；车三平四；士六进五；兵五进一
```

来源：C07-03。

思路：红方趁黑方阵型尚未完全联好，连续推进中兵，以马三进五、马五进六展开中路快攻。黑方常见应对是卒7进1或卒5进1，专题变化见 C08（尚未完整，不纳入本手册主线）。

### 3.6 过河车后的五六炮

```text
炮二平五；马八进七；马二进三；车九平八；车一平二；卒七进一；车二进六；马二进三；兵七进一；炮八平九；车二平三；炮九退一；炮八平六；车一平二；马八进七；炮二平一
```

来源：C07-04。

思路：六路炮兼顾三路马，可进炮骚扰，也可退炮转雷公炮。黑方若出直车，红方再用正马、中兵配合进攻。

### 3.7 左马盘河起横车

```text
炮二平五；马八进七；马二进三；车九平八；车一平二；卒七进一；车二进六；马二进三；兵七进一；马七进六；马八进七；车一进一
```

来源：C07-05。

黑方马7进6形成左马盘河，再车1进1，准备冲卒后车1平7反击红方三路线。红方可兵五进一求战（C07-06），黑方冲卒的时机和横车出动次序是核心。

## 4. 中炮对反宫马：五八炮主线

### 4.1 基本形与进七兵

```text
炮二平五；马二进三；马二进三；炮八平六；车一平二；马八进七；兵七进一；卒七进一
```

来源：C03-04、C23-01。

黑方炮8平6限制红方跳正马，但中卒仍是弱点。红方进七兵既活马，也限制黑方三路马。

### 4.2 五八炮进攻

```text
炮二平五；马二进三；马二进三；炮八平六；车一平二；马八进七；兵七进一；卒七进一；炮八进四；士四进五；炮八平五；马三进五；炮五进四
```

来源：C23-03、C23-05。

红炮八进四打中卒，黑方补士后红炮八平五，黑马3进5换炮，红方再炮五进四形成空心炮。

### 4.3 黑方车1平3反击与红方退马

```text
炮二平五；马二进三；马二进三；炮八平六；车一平二；马八进七；兵七进一；卒七进一；炮八进四；士四进五；炮八平五；马三进五；炮五进四；象三进五；马八进七；车一平三；车九平八；卒三进一；兵七进一；车三进四；马三退五
```

来源：C23-12。

黑方以车1平3、卒3进1从三路线出车，兼顾攻击七路马和抓中炮。红方马三退五，准备马五进七连环而出，避免强行跳马被黑车利用。

## 5. 中炮对列炮

### 5.1 大列炮：边马中卒弱点

基本形：

```text
炮二平五；炮二平五；马二进三；马八进九；车一平二；车九平八
```

来源：C24-01。

红方可炮五进四打中卒。黑士4进5后的课程变化：

```text
炮二平五；炮二平五；马二进三；马八进九；车一平二；车九平八；炮五进四；士四进五；炮八平五；马二进三；前炮退二；车一平二；前炮平三
```

来源：C24-03。

关键是前炮退二、前炮平三攻底象。黑方也可炮8平7兑车，红方兑车后以多中兵保持小幅主动，见 C24-04。

### 5.2 小列炮：七路马受压制

基本形：

```text
炮二平五；炮二平五；马二进三；马八进七；车一平二；车九平八；车二进六；炮八平九
```

来源：C24-08。

红方吃7卒的变化：

```text
炮二平五；炮二平五；马二进三；马八进七；车一平二；车九平八；车二进六；炮八平九；车二平三；车八进二；兵三进一
```

来源：C24-10。

黑方车8进2保马，红兵三进一，兼顾渡兵与进车抓炮。红方不宜机械走马四进二，以免黑方弃马打车并从三路线反击，见 C24-21。

## 6. 中炮对顺炮

### 6.1 直车对横车：现代双正马进三兵

共同起点：

```text
炮二平五；炮八平五；马二进三；马八进七；车一平二；车九进一
```

来源：C15-00。

现代主线：

```text
炮二平五；炮八平五；马二进三；马八进七；车一平二；车九进一；马八进七；车九平四；兵三进一
```

来源：C15-24。

思路：双正马保护中兵，再挺三兵活马。黑车9平4后，红方九路车不急于出动，先解决七路马和中路安全。

### 6.2 横车对直车：巡河车与双横车

共同起点：

```text
炮二平五；炮八平五；马二进三；马八进七；车一进一；车九平八；车一平六
```

来源：C16-00。

黑方推荐先车8进4巡河，以静制动：

```text
炮二平五；炮八平五；马二进三；马八进七；车一进一；车九平八；车一平六；车八进四
```

来源：C16-21。

双横车主线：

```text
炮二平五；炮八平五；马二进三；马八进七；车一进一；车九平八；车一平六；车八进四；马八进七；马二进三；车九进一；卒三进一
```

来源：C16-31。

黑方巡河车可随时左车右移，红方则马八进七后以双横车集中兵力。

## 7. 仙人指路对卒底炮

### 7.1 共同起点与黑方还中炮

```text
兵七进一；炮二平三；炮二平五；炮八平五；马二进三
```

来源：C40-00。

黑炮8平5形成带卒底炮的特殊顺炮。由于卒底炮占住二路马正位，中卒不能由双正马共同防守。

红方五六炮结构：

```text
兵七进一；炮二平三；炮二平五；炮八平五；马二进三；马八进七；车一平二；马二进一；炮八平六
```

来源：C40-05。

六路炮降低卒底炮对八路马的牵制。黑方出横车时要注意红方马八进七的时机，红车二平五保炮是后续关键（C40-08）。

### 7.2 黑象3进5：红炮打中卒

```text
兵七进一；炮二平三；炮二平五；象三进五；炮五进四；士六进五；相七进五；马二进四；炮五退一；车一平二；马八进六
```

来源：C41-01。

红方得中兵但黑方出子加快。炮五退一、马八进六保炮是重要次序；黑方常车9进1、车9平6攻击中炮。

### 7.3 黑象7进5：边马与边兵稳健线

```text
兵七进一；炮二平三；炮二平五；象七进五；马八进九；马二进一；车九平八；车九进一；马二进三；车九平六；兵九进一；车六进三；马九进八；卒一进一
```

来源：C42-03。

红马八进九先避冲卒，黑车1进1后多走车1平4，为马8进6留路。红兵九进一、马九进八是主要展开方式。

### 7.4 红左中炮与黑车8进5

```text
兵七进一；炮二平三；炮八平五；炮八平五；马八进七；马八进七；马二进三；车九平八；车九平八；马二进一；车一平二；车八进五
```

来源：C43-02。

黑方还中炮后抢出九路车，车8进5卡住红方骑河线，再冲3卒，限制红方七路马和中兵。红方也可先跳右马，黑方应先冲3卒改进，见 C43-05。

### 7.5 黑车9平8、炮3退1主线

```text
兵七进一；炮二平三；炮二平五；马八进七；马二进三；卒三进一；车一平二；卒三进一；马八进九；车九平八；车二进四；炮三退一；炮八进六；车一进一；车九平八；炮三进八；仕六进五；炮三退二；马三退一；车八进一；炮八退七；车一平三；炮八平七；马二进一；车八进二；卒三进一；车八进四
```

来源：C39-00。

这是一条已核实的完整课程主线，不是由多个独立片段拼接。重点包括炮八进六、左车保炮、炮3进8打相、炮八退七和车八进四。课程实际停在红车八进四，后续口述计划不擅自续写。

## 8. 飞相局

### 8.1 屏风马封车

```text
相三进五；炮八平四；马二进三；马八进七；车一平二；车九平八；炮二进四；卒七进一；炮二平三
```

来源：C44-03。

飞相后先求阵型协调，以炮二进四封车限制黑方巡河车右移。黑方挺7卒寻找跳马反击，红方炮二平三继续压马。

### 8.2 反宫马主线

```text
相三进五；炮八平四；兵七进一；马八进七；炮八平六；车九平八；马二进三；马二进一；马八进七；卒七进一；兵九进一；车一进一；车九进二
```

来源：C44-08。

先挺七兵限制黑方三路马，再以仕角炮形成反宫马结构。边兵和边马用于解决出车与边线控制，不急于强攻。

### 8.3 拐角马：独立摆定局面

起始 FEN：

```text
rnbakabnr/9/1c1c5/p1p1p1p1p/9/9/P1P1P1P1P/1C2B2C1/5N3/RNBAKA2R b - - 3 2
```

随后：

```text
马八进七；兵七进一；车九平八；车一平二；车八进四；炮二平三；车八平六；马四进六
```

来源：C44-10。

这是课程独立摆定的教学局面，不将摆子过程伪装成连续对局着法。红马四进六后，拐角马既可能形成攻击点，也可能挡住另一马腿，需结合全局处理。
